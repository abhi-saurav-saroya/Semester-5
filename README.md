## About

This repository contains academic coursework completed during the fifth semester of the **Bachelor of Technology in Computer Science and Engineering with specialization in Artificial Intelligence and Machine Learning** at IKGPTU.

The coursework is organized into two main categories:

1. **Practical Files** — Laboratory records, cover pages, and related academic documents.
2. **Practical Programs** — Source code and programming exercises organized subject-wise.

The repository is maintained to keep semester coursework organized and accessible for academic reference.
