## Running the Programs

Make sure **R** is installed on your system.

You can run any program from this directory using:
```bash
Rscript 1.R
```

Replace `1.R` with the name of the R program you want to execute.

If you are using RStudio, you can also open the .R file and run the program directly from the RStudio interface.
